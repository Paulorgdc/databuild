# Data

Everything in this folder except this file is local only and never versioned, not even in a private repository.

- `MED *.xlsx`: the six original monthly measurement workbooks. Read-only: never edit them or save over them.
- Anonymized derived copies for demos and presentations, when needed, must be generated later as separate files; the originals keep their real financial values and formulas.
- Results computed from these workbooks go to `outputs/` (also ignored).
